# V1.1 operations

## Configuration

Create one GA4 property and one web stream for the public deployed URL. Set the
repository Actions **variable** `PUBLIC_GA_MEASUREMENT_ID` to its public `G-` ID.
The ID is not a secret. Empty/unset values disable analytics; non-empty malformed
values and the example `G-XXXXXXXXXX` fail the production build and output check.
Never put credentials in `PUBLIC_*`, source, content or public files.
Only main push production builds receive this variable; PRs do not deploy.
Separate user-site and repository-path browser verification builds both use the
synthetic ID `G-123456ABCD` on PRs and main. They are overwritten by the final
production artifact build and never uploaded for deployment. Only this final build
receives the repository variable, and it runs `build` plus `test:build`, never a
browser. Browser tests reject non-synthetic IDs and mismatched HTML artifacts before
page navigation, intercept Google requests and use local artifact responses.
`SITE_URL` and `SITE_BASE` retain their existing CI-derived values.

Local development emits no analytics configuration. Ordinary local builds have
no ID and contain no Google tag bootstrap or host references. Even previewing an artifact configured with a production ID does not load
Google on a different origin. No local opt-in override is provided.

Disable all stream Enhanced Measurement options (including search, forms and
outbound clicks) before enabling the ID. V1.1 relies on the ordinary config page
view, uses canonical public paths plus approved campaign parameters, preserves
browser referrer behavior, and disables Google signals and ad personalization signals. Do not add private
data to public page titles or paths. Google still receives normal analytics/device
and network data and may use analytics cookies. The adapter is not a sanitizer
for Google's remotely configured features. No custom event hooks are installed.
The approved acquisition policy is specified in `docs/analytics-ga4.md`. Only
`utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, and `gclid`
may enter page_location; all other parameters and fragments are removed. Use
non-sensitive campaign tokens of 1–128 characters with the documented syntax.
Duplicate or invalid values are dropped. Never populate campaign links from search
queries, form text or personal data. Referrer is left to the browser default.

No banner or consent mechanism exists. This implementation does not claim consent
compliance. Leave the ID empty until the maintainer has selected an appropriate
consent approach for the deployment; do not interpret Consent Mode as a banner.

## Security review boundary

No dependencies were added. Frozen installs and pinned Actions remain in place.
Only deploy has Pages write/OIDC permissions; required human reviewers and the
main-only branch restriction must be verified in GitHub environment settings.
These hosted settings cannot be proven from YAML or local tests.

Current external links open in the same tab. Future `target="_blank"` links must
use `rel="noopener noreferrer"`. Configurable Project URLs now reject executable
schemes and credentials; hosting already validates HTTP(S) origins. Author URLs
are trusted source constants. Markdown contains trusted static diagram HTML;
review content changes as code. Do not ingest untrusted Markdown/MDX. The sole
`set:html` use is JSON-LD serialized by `safeJson`, with script-termination tests.

No CSP is currently emitted and no wildcard or new domain allowlist was added.
The optional policy is deferred until inline theme, Astro and Pagefind behavior
can be tested together. GitHub Pages custom server headers, frame protection and
Report-Only policies are not claimed. GA4 is the sole new remote script, fetched
from `https://www.googletagmanager.com/gtag/js`; this is gtag.js, not a GTM container.
Its failure does not gate site behavior.

## Deployment verification (maintainer)

After independent review and approved deployment, inspect Network for one Google
tag per document and GA4 collection requests, then check Realtime hostname/path.
Verify approved campaign identifiers survive in page_location, arbitrary parameters
and fragments do not, and referrer is not overridden. Confirm no search/form text
is added by the site. Local tests block Google and cannot prove remote payloads.
Block Google requests and verify navigation, search, theme and language controls.
Verify stream settings and the GitHub environment protections directly. Local
stubbed tests cannot confirm GA4 property creation, delivery or Realtime reporting.
